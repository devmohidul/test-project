# Test Project

A Node.js project built with TypeScript and Next.js, used for development in Cursor.

## Tech stack

- **Node.js** — runtime
- **TypeScript** — language
- **Next.js** — web framework (App Router)
- **dotenv** — environment variables

## Getting started

Requirements: a current Node.js LTS release.

```bash
npm install
```

## Scripts

```bash
npm test
```

The test script is a placeholder until tests are added.

## Project layout

- `package.json` — project metadata and dependencies
- `cursor.md` — tech stack notes and conventions
- `README.md` — this file

Application code will live in the Next.js structure (`app/`, `components/`, `lib/`) as the app is scaffolded.
